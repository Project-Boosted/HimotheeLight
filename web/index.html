AUTOMATIC GAME LOGIC

What changes the base state?

✓Autodarts match page → Active lighting
✓Match Shot / leaving match → Idle lighting after celebration
✓Board Manager Started/Stopped remains the fallback when the bridge is unavailable
✓Starting mid-session synchronises from running
✓Throw events update the live dashboard
✓Automatic reconnect after a dropped local connection
✓Trigger engine listens to darts, visits, combinations, targets, Bust, Game Shot, Match Shot and player turns
✓Third dart → solid yellow until the player removes the darts
✓Darts removed / Takeout Finished → solid red for 500 ms → current match colour
✓60 seconds without a dart → latched Idle until a new game becomes active

SCENE ACTION

Add WLED action

Actions in the same step run together. Higher step numbers run afterwards. Hue targets use on/off, brightness, Colour 1 and transition; WLED targets additionally use effects, palettes, speed, intensity and presets. Delay is measured from the start of that step, and Hold controls how long the step stays active before HimotheeLight advances. If two actions in the same moment target the same device, the later action wins.
