HimotheeLight v0.8.0 - Autodarts Game Bridge

UPDATE / ONE-TIME SETUP (Chrome)
1. Start HimotheeLight normally.
2. Open chrome://extensions
3. Turn Developer mode ON.
4. If an older HimotheeLight Autodarts Bridge is loaded, either:
   - press Reload after replacing it with this v0.8.0 browser-extension folder, or
   - remove it and click Load unpacked.
5. Select the browser-extension folder inside this HimotheeLight-v0.8.0 folder.
6. Refresh your Autodarts page.
7. In HimotheeLight open Autodarts -> Game Bridge.

Expected status:
- Autodarts lobby/other page: BRIDGE CONNECTED
- Autodarts match page: MATCH CONNECTED / AUTHORITATIVE
- ATC / RTW / Shanghai / Bob's 27: Current target should populate when available

Edge: use edge://extensions and the same steps.

The bridge sends normalized match/game fields only to the local HimotheeLight
server at http://127.0.0.1:8765. It does not ask for your Autodarts password or token.
